# Hybrid Credit Risk Classification

This repository contains the code, processed datasets, experimental configurations, figures, and complete results associated with the research paper on a hybrid supervised machine learning framework for credit risk classification.

## Repository Contents

- `01_Dataset_Audit.ipynb` – Dataset validation, distributions, missing values, and descriptive analysis.
- `02_Preprocessing_Protocol.ipynb` – Data cleaning, encoding, scaling, and preprocessing pipelines.
- `03_Baseline_Models.ipynb` – Evaluation of baseline machine learning models.
- `04_German_GroupAware_Feature_Selection.ipynb` – Feature-selection development using the German Credit dataset.
- `05_Frozen_Feature_Selection_Replication.ipynb` – Replication of the frozen feature-selection protocol.
- `06_Cost_Sensitive_XGBoost_Ablation.ipynb` – Cost-sensitive XGBoost ablation experiments.
- `07_German_Heterogeneous_Ensemble_Development.ipynb` – Development of the heterogeneous ensemble.
- `08_Frozen_Hybrid_Ensemble_Replication.ipynb` – Cross-dataset replication of the frozen hybrid ensemble.
- `09_German_Probability_Calibration_Development.ipynb` – Probability-calibration development.
- `10_Frozen_Sigmoid_Calibration_Replication.ipynb` – Replication of sigmoid calibration.
- `11_German_Cost_Sensitive_Threshold_Development.ipynb` – Development of the cost-aware decision threshold.
- `12_Frozen_Cost_Aware_Threshold_Replication.ipynb` – Cross-dataset replication of the frozen threshold rule.
- `13_Final_Ablation_Statistics_and_Fairness.ipynb` – Final ablation, statistical testing, and fairness analysis.
- `14_Final_Explainability_Analysis.ipynb` – Permutation importance and SHAP-based explainability analysis.
- `data/processed/` – Cleaned datasets used by the notebooks.
- `figures/` – Dataset-audit figures.
- `pipelines/` – Saved preprocessing objects.
- `results/` – Fold-level results, predictions, statistical summaries, configurations, and manuscript-ready tables.

## Datasets

The experiments use three benchmark credit-risk datasets:

1. German Credit
2. Australian Credit Approval
3. Default of Credit Card Clients (Taiwan)

The processed versions used in the experiments are included in `data/processed/`.

## Reproduction Instructions

1. Download or clone this repository.
2. Create a Python environment.
3. Install the required Python packages.
4. Start Jupyter Notebook or JupyterLab.
5. Run the notebooks sequentially from `01_Dataset_Audit.ipynb` to `14_Final_Explainability_Analysis.ipynb`.
6. Generated outputs are stored in the corresponding folders under `results/`.

The notebook numbering represents the required experimental execution order.

## Experimental Design

The repository documents:

- Dataset auditing and preprocessing
- Baseline model evaluation
- Group-aware feature selection
- Cost-sensitive learning
- Heterogeneous ensemble development
- Cross-dataset frozen replication
- Probability calibration
- Cost-aware threshold optimization
- Ablation analysis
- Corrected statistical comparisons
- Fairness assessment
- Model explainability

Configuration JSON files and output manifests are included to support verification of the experimental protocol.

## Reproducibility Note

The supplied result files are the outputs generated by the corresponding notebooks. Reviewers can inspect the notebook code, experimental configurations, fold-level results, predictions, summary tables, and figures to verify the reported findings.
